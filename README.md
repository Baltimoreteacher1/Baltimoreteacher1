## Where did all the other repos go?

**They're archived, not deleted.** 100+ individual activity repos (like `6.EE.C.9Game`, `Mean-Median-Mode-Game`, etc.) are now archived because their content lives in the [Classroom Hub monorepo](https://github.com/Baltimoreteacher1/neft-classroom-html-activities). All existing URLs and deployments still work.

To see archived repos: go to your [Repositories tab](https://github.com/Baltimoreteacher1?tab=repositories) and filter by "Archived".

To unarchive a repo: go to the repo → Settings → Danger Zone → Unarchive.

## Quick Deploy Guide

**Add a new activity to the hub:**

1. Clone `neft-classroom-html-activities`
2. Add HTML file in the right folder (e.g., `math/unit-5/my-activity/index.html`)
3. Push to `main` — Cloudflare auto-deploys

**Deploy a standalone repo to Cloudflare Pages:**

1. Create a new repo on GitHub with `index.html`
2. Go to [dash.cloudflare.com](https://dash.cloudflare.com) → Pages → Create
3. Connect your GitHub repo, set build output to `.`
4. Auto-deploys on every push
