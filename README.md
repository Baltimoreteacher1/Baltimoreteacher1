## Quick Deploy Guide

**To add a new activity to the main hub:**

1. Clone `neft-classroom-html-activities`
2. Add your HTML file in the right folder (e.g., `math/unit-5/my-activity/index.html`)
3. Push to `main` — Cloudflare auto-deploys

**To create a standalone activity:**

1. Create a new repo on GitHub
2. Add `index.html`
3. Go to repo Settings → Pages → Deploy from branch `main`
4. Live at `baltimoreteacher1.github.io/repo-name/`

**To deploy to Cloudflare Pages:**

1. Go to [dash.cloudflare.com](https://dash.cloudflare.com) → Pages → Create
2. Connect your GitHub repo
3. Set build output to `.` (root) for static HTML
4. Auto-deploys on every push
